# AirSIM「暖橙」界面设计规范

版本：2026-11-20 · 设计交付 · iOS 16.3+

交付范围：只设计暖橙主题。墨绿、天蓝的布局及行为保持原样。未修改 App 源码。`mockup.html` 是可离线打开的单文件静态设计稿；每个场景提供 390 × 844 的浅色、深色画框。HTML 中的像素对应稿件中的 pt，仅用于设计展示，不是 App 实现。

## 1. 为什么第一版「太 AI」

这里的问题不是“用了橙色”，而是组件在抢内容的注意力。

- **首页重复解释同一件事。** current-light/current-detail 中，“当前设备：未配对”卡片已有添加按钮，下一张又是推广式“添加设备”，第三张仍是“还没有号码”。空数据占了三张大卡片，而用户下一步只有一个：添加设备。“下午好”进一步挤占首屏，但没有帮助打电话。
- **视觉容器过多，优先级过少。** 22pt 左右的圆角、浅描边、投影、米色图标圆底，在首页、设置和留言里重复；不同重要性的内容得到相同的包装。第一版代码还把渐变用于主按钮、添加入口和统计块，装饰成为统一语言，却没有交代哪条线路可用。
- **信息密度用错地方。** “我的”用两张大数字卡统计设备和号码，具体设备状态被推到屏幕外。语音信箱把播放、号码、时间、两个动作并排挤在短行里，主号码和接收线路截断，时间重复。陌生号码本来就是辨识来电的主体，不能让给图标。
- **圆体与柔软轮廓叠加，弱化工具属性。** 标题、号码、正文都用圆体，配合大量胶囊与卡片，像通用生活方式模板。电话/SIM 工具应让号码、方向、线路来源成为视觉骨架。
- **橙色承载太多意思。** 添加、版本号、线路、头像、未读点、播放、导航都抢同一饱和度；状态、内容和动作没有区分。
- **深色像整体染成棕色。** current-dark 中，各种棕黑底与低亮度辅助字之间的区分不够明确，细小离线状态更弱。深色应保留清晰层次，而不是给浅色加棕色滤镜。
- **失败状态缺少行动。** current-detail 的彩信以放大的图片警告符号占满气泡，没有“加载失败”说明和明确重试动作。大图标不等于有用的反馈。

参考图值得保留的是：稳定的四栏导航、开阔的拨号区、统一的通话子导航、按时间组织的通信记录，以及明确的橙色操作。参考图也有余额推广、大卡片和圆底图标；这些不适合 AirSIM 的数据与任务，不予照搬。不使用参考产品品牌、人物、邮箱或号码。

**设计原则**

1. **先号码，再来源，再动作。** 当前发出线路与每条记录的经由线路都明确可见。
2. **平面列表是默认，容器必须有理由。** 通过空白、基线和分隔线分组；只有当前线路、弹层、输入域和设置组使用底色容器。
3. **暖来自纸白与少量铜橙。** 主操作、当前选择、未读使用橙；正文用近黑，元信息用足够对比的灰，错误用红。
4. **一个位置解决一件事。** 首页管理当前线路和设备；通话完成电话任务；短信处理消息；我的放设置。没有欢迎语、营销卡、虚构账户或余额。
5. **状态不能只靠颜色。** 在线伴随“云端/局域网/蓝牙”；未接有文字与方向符号；禁用有原因；失败有恢复动作。

## 2. 信息架构与数据约定

```
首页 ─ 当前线路 → 选择线路（全局）
     ├ 拨号 / 发短信 → 通话·拨号 / 新建短信
     ├ 其他线路 → 选择线路（全局）
     ├ 未接、未读提醒 → 最近·未接 / 短信
     └ 设备列表 → 既有设备详情；添加设备 → 既有配对流程
通话 ─ 拨号 / 最近 / 联系人 / 语音信箱
     ├ 最近详情 → 回拨 / 发短信 / 留言
     ├ 联系人详情 → 按号码拨打 / 发短信
     └ 留言 → 播放、进度、回拨、短信、清空
短信 ─ 搜索 / 新建 / 更多·清空全部短信
     └ 会话 → 文字、验证码、图片、语音、发送状态、选图
我的 ─ 默认线路 / 连接与设备 / 来电与短信 / 外观与偏好
     └ 连接状态 / 帮助与诊断 / 意见反馈 / 关于 AirSIM / 全部设置
```

- 底栏固定为“首页 / 通话 / 短信 / 我的”。通话内显示“拨号 / 最近 / 联系人 / 语音信箱”。回到通话保留本次会话选中的子页，首次进入选拨号。
- 线路身份是 **设备 ID + SIM 卡槽 ID（或 voip.ms DID 对应的线路 ID）**，不能只用末四位、运营商或显示名识别。默认切换成功后同时更新设备与 SIM 卡槽。通话建立中、响铃中、通话中均不能切换全局线路。
- 每条线路主显示完整号码，第二行显示设备别名、运营商、卡槽（适用时）。无号码时显示“号码未知”，仍保留设备名和“SIM 1 / SIM 2”。切勿编造号码。
- 首页当前线路是默认发出线路。回拨默认使用该记录的原线路；若原线路缺失/离线，先让用户选可用线路，保留待拨号码。联系人拨号使用全局默认线路并在拨出前可见。
- **已有短信的回复线路独立于全局默认。** 会话按对方号码聚合；顶部标明本次回复实际来源。优先沿用最近一条消息的设备与槽位；同一个对方跨线路时，在时间线的线路改变处插入“经由 {完整号码}”。用户可在会话专属选择器切换回复线路，不改变全局默认。切换前保留草稿，不自动发送。
- 读到的现有 `MessageThreadView` 已按最近消息取回复设备，但 `SMSAccountPicker` 取当前设备。实现时必须把“显示的发送线路”和“实际发送设备+槽位”绑定到同一有效身份；这是设计验收项，不允许只改表面标签。
- 线路归属若只有设备、没有槽位：显示“{设备} · 卡槽未知”，要求用户在可选槽位中确认后再发送；如果系统只有一个有效槽位可直接解析。记录没有源信息时显示“线路未知”，不猜成当前线路。
- 已缓存的通话、短信、图片、音频在设备离线时仍可阅读/播放。只有需要实时连接的动作禁用；明确区分“无历史记录”与“加载失败”。
- 短信“未读”和音频“未听”是两个独立状态：打开含语音的短信会话只清除会话未读；音频实际成功播放才标已听。播放失败不清标，两个入口共用同一音频播放/已听状态，不能继续用一个未读集合代替两种语义。
- 语音信箱仅对应 voip.ms，列表汇总所有 voip.ms 线路；默认选安卓时仍可查看已存在的留言。非 voip.ms 且没有留言时显示支持说明。音频附件是否为留言由数据标识判断，不能把任意音频都当语音信箱。
- 示例数据全部虚构：联系人“林青 / 周宁 / 陈岚”，设备“家中 K40 / 备用安卓 / voip.ms”，加拿大线路 `+1 236 555 0102`、`+1 672 555 0108`，对方号码使用 555-01xx 示例段；中国示意号用 `+86 138 **** 0426`，不用于实际输入。例图中的姓名不代表真实人物。生产环境展示实际号码，不照搬掩码。

### 3.3 布局、表面与图标

- 基本网格 4pt：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。页面横向边距 20；行内容水平 0（平面列表）或 16（设置组）；触控至少 44 × 44。默认可用宽度 350。
- 390 × 844 稿：顶安全区 47，底安全区 34；底栏内容区 49，总高 83；根页标题区 64。正文区可滚动；push 页隐藏底栏。真实设备以系统 safeAreaInsets 为准，不硬编码刘海。
- 根页标题滚动时收为 17pt 标题，系统行为；拨号页标题与分段固定。push 导航区基准 44，含双行会话标题时 56–64。
- 圆角：设置组和当前线路 12；搜索/输入域 10；次按钮 10；分段外 10、选中 7；短信气泡 16；图片 12；弹层顶部 20（系统表现可适配）；小标 4。只有拨号键、头像、播放键可圆形。底栏不悬浮、不做胶囊。
- 描边：分隔线 1 个物理像素（设备 scale 倒数）；输入与次按钮 1pt；当前线路只用 1 像素边缘，不叠投影。HTML 以 1 CSS px 近似细线。
- **阴影全部为 0**；系统 sheet/系统键盘自带层级不覆盖。所有 App 背景与按钮不使用渐变、光晕、玻璃磨砂或纹理。
- 图标统一 SF Symbols monochrome，常规 20pt / regular；标题操作 22 / regular；底栏 23 / regular，选中可用 fill / semibold；行尾 chevron 12 / semibold；辅助状态 14 / regular。每个 20pt 图标分配 24pt 光学槽位。示意稿用内联线性 SVG 近似，iOS 按下表使用 SF Symbols，不把示意 SVG 当最终资产。

| 线路 / 安卓设备 / voip.ms | simcard；smartphone；network |
| 添加 / 新建 / 搜索 / 更多 | plus；square.and.pencil；magnifyingglass；ellipsis |

图标不可用时退回同类基础符号，最低 iOS 16.3 验证可用性。蓝牙/局域网/云端优先用文字显示，不凭网络图标臆断连接质量。

## 4. 组件规格

### 4.1 导航、标题与分段

- **底栏**：surface 底、顶部 separator 细线、4 等分。图标 23，上距 6；标签间隔 3。非选中 textSecondary；选中 accent + fill 图标。未读角标在图标右上，最小 16 × 16，数字 10pt semibold，accentFill/onAccent，超过 99 显示 99+。通话角标=未查看未接数（不加留言）；短信角标=未读会话数（不把同一留言重复计入两套数字）。语音未听数只在语音信箱子页入口显示。
- **页面标题**：左侧 28pt，右侧最多两个 44pt 操作；短信为更多、新建。首页仅添加设备（plus，VO“添加设备”）；不放问号圆按钮与问候语。常驻在线状态只描述当前线路，不写全局“在线”来掩盖其他离线设备。
- **通话子导航**：350 × 44；surfaceMuted 轨道，3pt 内边；宽度按标签分配 68 / 74 / 78 / 124，其余作为边距；选中 surface、无阴影。文字 14pt medium，选中 semibold。最近、信箱的小数量与标签同一水平，不挤掉文字；超过 9 用 9+，完整数 VO 读出。
- Dynamic Type XXXL 及以上：四分段改成一行可横向滚动的标签按钮，最小 44 高并自适应，保持选中项可见；不缩字号。AX 大字号下可改 2×2 的四项选择组，按阅读顺序排列，说明和切换逻辑不变。

时间格式：今天显示“09:24”；昨天“昨天”；更早“11月18日”；详情/展开行显示“今天 09:24”，跨年带年份。通话时长“2分18秒”；音频计时“00:24”。未知时长“时长未知”，不显示假的 0。未接有留言时独立文字链接“有语音留言”，无留言则不留空徽章。来源不明确用“线路未知”。

### 4.3 按钮、状态、搜索与反馈

- 主按钮：高48、横内边16、radius10、accentFill/onAccent、16 semibold；整页通常一个。按压使用深浅模式各自 accent 的亮度变化或 surfaceMuted 覆盖（10%），不缩放。禁用 disabledFill/textDisabled，旁边/上方展示原因。
- 次按钮：高48、radius10、透明或surface、controlBorder 1、textPrimary。文字按钮最小44高，accent，无底色；破坏动作 danger。图标按钮44×44，不附加圆底，除播放与拨号。
- 在线点6，positive，间隔6后必须有“云端 / 局域网 / 蓝牙 / 离线”文字；离线为灰色点。未知状态用空心点+“状态未知”。不把电量未知显示为0%。
- 默认标记：12pt semibold，水平6/垂直2，radius4，accentSoft/accent，文案“默认”。选中勾不和“默认”混为一谈：会话发送线路可与全局默认不同。
- 未读点6或8，accent；VO 包含“未读”；短信未读数量底栏汇总，列表不堆叠每条数字。未听用点+“未听”，播放开始后转“已听”。
- 搜索框：最小44高，surfaceMuted，radius10，左16pt放大镜，间隔8，文字17。激活显示系统键盘与“取消”；有内容显示44触控的清空符号。默认文案“搜索姓名、号码或内容”/“搜索联系人”。搜索内容需匹配历史短信正文，命中高亮仅用字重与accentSoft，不替换原文。
- 提醒条：满内容宽、最小48，warningSurface，左18pt图标，文字14/20；行动单独文字按钮44高。多条提醒按“当前动作阻断 → 未接 → 未读”排序；最多一条阻断条+一行通信摘要。离线只点名涉及的设备，不阻止其他在线线路。
- 空状态：在内容区顶部下移64，裸图标28、距标题16、标题20 semibold/28、说明15/22，最多3行，动作间距24。无阴影、无大插画、无装饰卡。首次无设备只有一个主按钮“添加设备”。
- 加载：有缓存保留列表，标题下16pt微型spinner+“正在更新…”；首次加载用3条静态中性占位（无闪光扫动），VO读“正在加载…”。8秒仍未完成保留取消/返回，失败显示“加载失败”+“重试”，绝不切换成空列表。

### 4.4 线路选择器

- 原生 sheet，背景 surface，圆角20，顶部抓手36×5，标题17，关闭44。少量线路默认 medium，可拉到 large；超过3条或大字直接 large。内容可滚动，最后一行不能藏在底部安全区。
- 标题按上下文为“默认线路”“拨号线路”“发送线路”；副说明分别“用于下一次拨号和新建短信。”“用于本次拨号。”“仅用于当前会话，不更改默认线路。”。
- 按设备分组，组头显示名称、连接方式。行以号码为主，运营商/卡槽在下，右侧 checkmark 表当前选择。选择成功即关闭，轻触反馈一次，提示“已切换到 {号码}”。失败不换勾、不关闭，行下显示“切换失败，请重试”。
- 默认线路设置允许记住离线线路，但显示“设备离线，暂时无法拨号或发送短信”；本次拨号/发信选择器把离线行禁用并给原因，绝不静默改用另一条线。
- 通话期间仍能打开并读列表，所有切换行禁用；顶部提醒“通话中不能切换线路”，关闭可用。等待建立的呼叫同样适用。
- 无线路显示“还没有线路”与“添加设备”入口；槽位未加载显示“正在读取线路…”，失败“线路读取失败”“重试”。列表底“添加设备”是普通行，不是营销卡。

### 4.5 拨号盘

- 390宽默认布局：标题64 → 分段44 → 号码区约120 → 线路行48 → 键盘4×72（行距4）→ 动作区76 → 底栏83。号码区和键盘之间可弹性分配剩余空间，不用大空白把拨号键推离拇指。
- 数字区居中32pt、40行高；匹配联系人14pt在下一行。长号码不缩到不可读：超过可用宽度时在输入行横向滚动到末尾，VO读完整号码。长按输入区可粘贴；无号码时显示“输入号码”，不显示虚假示例号码。
- 12键3列，列宽约104，触控区最小80×72，间距12；数字34，字母10，0下方“+”。**平面无圆底数字**，按下时临时出现64圆形surfaceMuted。0长按0.45秒输入+，轻触仍是0；VO自定义操作“输入加号”。不重复触发。
- 拨号键64×64圆形，accentFill，phone.fill 27/onAccent；旁边删除44（仅有号码时显示），长按删除连续退格，VoiceOver另有“清除号码”。有匹配联系人也不自动拨出。
- 空号码、无可用线路、通话中拨号键禁用。无号码文案“输入号码后拨打”；离线在键盘上方显示阻断说明+“选择其他线路”；通话中显示“通话中，暂不能再次拨号”与“返回通话”。数字仍可编辑/复制，但不建立第二通。

### 4.6 消息、媒体与输入栏

- 时间线水平16，气泡最大可用宽度80%（390下约286），收左发右，最小44高、内边12/10、圆角16，连续同一方向消息间隔6，不同方向12；**不加气泡尾巴、渐变、阴影**。收件surfaceMuted/textPrimary；发件accentFill/onAccent。长链接允许断行；选择文本保留原生菜单。
- 消息字体17/25，时间12/17置于气泡外或时间分组中。每次来源切换插入一条居中的“经由 {号码}”，字体12；默认顶部的发送线路不替代历史来源。
- 验证码：保留完整短信正文，在正文下增加44高的复制行，22pt等宽数字+18pt doc.on.doc，说明“点按复制验证码”。正文中的验证码可accent强调但不从原文删除。点击只复制数字，反馈“验证码已复制”持续2秒，VO播报一次。仅有明确可识别验证码才出现，不把所有数字识别为验证码。
- 图片：默认最大260×200，radius12；按实际比例缩放、列表中长图限高240；点按全屏查看原图。不给图片盖橙色蒙版。加载先保留同尺寸中性底+小spinner+“正在加载图片…”；失败用28pt photo、两行说明“图片加载失败”“点按重试”，保留原图片占位尺寸；不把SF Symbol拉伸为整张图片。
- 语音：最小240×84，播放44，名称14/20，进度轨道4，时间12；暂停保持播放位置；拖动命中区44高，VoiceOver可调整每次5秒（若底层尚不支持seek，工程需补齐，不能显示假可拖进度）。同时仅播放一条，来电/系统音频中断即暂停。
- 发送状态在发件气泡下方：发送中… / 已发送 / 发送失败 · 重试。**已发送不等于已送达或已读**，无投递回执不得展示“已送达”。失败后保留草稿内容和气泡，点重试仅重发该条，不复制两条。图片下载失败与短信发送失败为不同状态。
- 输入栏surface，顶部细线，横12，纵8；照片44、间隔8、输入框最小44（radius10、controlBorder）、发送44；正文17，1–5行增长，超过后内部滚动，键盘出现时固定于键盘顶。空消息发送键可见但禁用，不造成输入宽度跳动。底部安全区34，键盘显示后由系统管理。
- 待发图72×72，移除按钮视觉20、触控44；选图后发送是“发送彩信”，输入提示“添加说明”。只在实际支持MMS的线路提供照片入口，不能只按地区猜能力。不支持时首次切换提示“此线路不支持彩信”，保留待发图并禁用发送，让用户切回支持线路或移除图。
- 会话顶部左返回44，中间姓名17/24+对方号码12/17（无姓名时号码17），右电话44。发送线路独占下一条44高行（文字14，chevron），保证来源看得清；拨号使用该会话可解析的当前线路。
- 会话离线仍能编辑草稿，发送按钮禁用并显示“线路离线，草稿已保留”。通话中禁用线路切换；同线短信是否可发按实际能力决定，若服务不允许则显示“通话中，暂不能发送”；不一刀切阻断查看消息。
- 长按消息保留“复制 / 选择 / 删除 / 分享”，选中模式显示“已选 {n} 条”“删除”“分享”“取消选择”；删除确认描述作用范围，沿用既有本地删除行为。

- Dynamic Type：所有文字用可缩放语义，不能把上表字号写成不可缩放的常量。至XXX(L)行高增长、说明与时间换行；AX1以上列表行变为“主信息 → 元信息 → 动作”的纵向结构，取消右侧竞争宽度。电话号码完整换行或允许横向查看，不全局minimumScaleFactor。底栏继续保留文字，49内容区随字体升到至少64–72，底安全区独立加；VoiceOver大内容查看器可用。
- AX大字号拨号：数字也缩放，键盘行高随之增长；整个拨号内容可滚动，拨号操作通过安全区插入保持可达。不要为了塞进844高而限死Dynamic Type。所有scroll内容必须能滑到最后。
- VoiceOver顺序：页标题→分段→提醒→主内容→操作→底栏。列表行作为信息组，内置动作可单独聚焦或通过accessibilityActions进入，不把按钮吞入纯文本。线路例：“加一，二三六，五五五，零一零二。voip.ms，云端，默认线路。按钮。”数字逐位朗读，国家码说明，不读成千亿整数。
- 选中分段带selected trait；底栏读“短信，3个未读会话，标签，3/4”；禁用读原因，且仍可发现。只用颜色的点必须有文字语义，不重复播读装饰符号。
- 音频进度为adjustable并报当前/总时长；复制、切换、失败用一次announcement，计时秒数不每秒打断读屏。来电交给既有CallKit流程，不额外抢焦点。
- 系统减少动态效果：禁用平移，保留0–100ms淡入；增加对比度提高边界；减少透明度时弹层遮罩保持实色层次。横屏/小屏按自适应滚动规则，不让按钮落出安全区。
- 实现验收设备至少390×844与375×667；浅/深；Large、XXXL、AX3、AX5；最长设备名24字、全长国际号码、未读99+、5行输入、横屏。HTML默认静态稿不构成原生Dynamic Type或VoiceOver实现通过证明，工程师需在原生端实际验证。

## 7. 交互与动效

- 导航push/pop与sheet使用iOS默认；主题切换颜色150ms交叉淡化；分段选中背景120ms平移或淡化，无弹簧超调。
- 按下反馈即时（≤100ms）；普通列表无入场错峰、无卡片飞入；下拉刷新用系统控件。删除确认走原生交互。
- 切换线路只在成功时一次selection haptic；验证码复制一次轻反馈；拨号按键是否发DTMF沿用现有设置，不新增持续震动。错误反馈不连续震动。
- 留言展开约180ms高度动画，暂停/播放图标80ms淡换；进度线真实跟随播放。后台/音频中断后恢复状态，不自动恢复播放。
- 清空前明确范围并确认；取消不改变记录。发送只由明确点发送触发；选择照片、切线路、取消权限都不能顺便发送。

## 9. 不要做

- 不改墨绿/天蓝的导航与样式，不在共享组件上无条件覆盖暖橙颜色。
- 不照搬参考产品的品牌、Logo、账户姓名、邮箱、号码、余额、充值、套餐、订阅或到期逻辑。
- 不加“早上好/下午好”、装饰性统计卡、推荐套餐、推广式添加卡、服务器域名个人资料卡。
- 不所有内容套圆角+阴影，不给每个图标垫米色圆，不用全局圆体，不做橙色渐变、发光悬浮按钮、玻璃底栏。
- 不用橙色涂满每条经由线路、版本号和所有辅助说明；不要将浅灰说明做到难以阅读。
- 不牺牲电话号码宽度给三个同行按钮；不隐藏发送线路，不用末四位作唯一标识，不在失败后静默换线路。
- 不把未配对、无记录、权限拒绝、离线和加载失败画成同一个空状态。
- 不用大警告图标替代失败说明；不显示假波形、假进度、假回执、假电量和没有后端依据的自动删除期限。
- 不把动态字体限制在默认大小；不只靠颜色传递未读/未接；不让44pt触控区相互覆盖。
- 不在用户选择线路/照片/联系人时自动发起通话或发送；不在清空时隐瞒本地范围与留言/短信共享删除影响。
